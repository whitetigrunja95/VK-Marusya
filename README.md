# VK Маруся

Веб-приложение для поиска и просмотра информации о фильмах.

## Демо

https://vk-marusya-gamma.vercel.app/

## Функционал

* Случайный фильм на главной странице
* Топ-10 фильмов
* Просмотр фильмов по жанрам
* Поиск фильмов
* Страница фильма с подробной информацией
* Добавление фильмов в избранное
* Страница аккаунта пользователя
* Адаптивный интерфейс для мобильных устройств

## Технологии

* React
* TypeScript
* Vite
* React Router
* REST API
* LocalStorage

## Запуск проекта

Установка зависимостей:

```bash
npm install
```

Запуск в режиме разработки:

```bash
npm run dev
```

Сборка проекта:

```bash
npm run build
```

Предпросмотр production-сборки:

```bash
npm run preview
```

## Структура приложения

### Главная страница

* Случайный фильм
* Топ-10 фильмов

### Жанры

* Список жанров
* Страница жанра
* Пагинация

### Страница фильма

* Информация о фильме
* Трейлер
* Добавление в избранное

### Аккаунт

* Информация о пользователе
* Список избранных фильмов

## Особенности реализации

* Клиентская маршрутизация через React Router
* Хранение избранного в LocalStorage
* Обработка состояний загрузки и ошибок
* Адаптивная верстка для мобильных устройств
